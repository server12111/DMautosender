# Политика конфиденциальности AutoSender DM

Опубликовано: https://telegra.ph/Politika-konfidencialnosti-DMautosender-08-03
Дата последнего обновления: 3 августа 2026

Настоящая Политика конфиденциальности (далее — «Политика») определяет порядок обработки и защиты персональных данных пользователей сервиса AutoSender DM (далее — «Сервис»), предоставляемого через Telegram-бота @feAutoSenderDMbot. Используя Сервис, пользователь подтверждает своё согласие с условиями настоящей Политики.

## 1. Какие данные мы собираем

Для работы Сервиса мы собираем и обрабатываем:

- ваш Telegram ID и username;
- данные Telegram-аккаунтов, которые вы самостоятельно добавляете для рассылок (сессии авторизации);
- список получателей и историю ваших рассылок;
- сведения об оплате подписки — без хранения полных платёжных реквизитов: оплата обрабатывается платёжными провайдерами.

## 2. Как мы используем данные

Собранные данные используются исключительно для:

- обеспечения работы функций Сервиса (авторизация аккаунтов, запуск и учёт рассылок);
- технической поддержки пользователей;
- уведомлений о статусе подписки и рассылок;
- анализа и улучшения работы Сервиса.

Добавленные Telegram-аккаунты используются только для выполнения задач, инициированных самим пользователем, и не используются в иных целях.

## 3. Передача данных третьим лицам

Мы не передаём персональные данные пользователей третьим лицам, за исключением случаев:

- когда это требуется действующим законодательством;
- при обработке платежей — платёжным провайдерам, в объёме, необходимом для проведения платежа;
- с явного согласия пользователя.

## 4. Хранение и защита данных

Данные аккаунтов и сессии хранятся на защищённых серверах с ограниченным доступом. Срок хранения данных соответствует сроку использования Сервиса; после удаления аккаунта пользователем связанные с ним сессии и данные удаляются. Пользователь вправе в любой момент удалить добавленные аккаунты и данные из Сервиса самостоятельно через интерфейс бота.

Несмотря на предпринимаемые меры защиты, ни один способ передачи данных через интернет не может быть гарантированно защищён на 100%. Администрация не несёт ответственности за ущерб, возникший в результате обстоятельств, находящихся вне её разумного контроля (действия третьих лиц, сбои в работе Telegram и т.п.).

## 5. Права пользователя

Пользователь вправе запросить информацию о хранимых данных, потребовать их удаления или ограничения обработки, обратившись в поддержку Сервиса.

## 6. Изменение политики

Администрация вправе вносить изменения в настоящую Политику. Актуальная редакция всегда доступна по ссылке в боте. Продолжение использования Сервиса после публикации изменений означает согласие с обновлённой редакцией.

## 7. Контакты

По всем вопросам, связанным с обработкой данных, обращайтесь в поддержку через бота @feAutoSenderDMbot.
